# Requisitos no funcionales

## Estado

No se han aprobado objetivos no funcionales concretos. Este documento enumera decisiones necesarias sin asignar valores ni tecnologías.

## Pendientes

### Rendimiento

- tamaños de tablero objetivo;
- tiempo máximo de generación;
- tiempo máximo de carga y guardado;
- valor numérico del presupuesto global de nodos, que se fijará mediante benchmarks sobre los tamaños aprobados.

### Compatibilidad

- navegadores y versiones soportados;
- escritorio, tableta y móvil;
- funcionamiento sin conexión.

### Accesibilidad

- nivel WCAG objetivo;
- navegación por teclado;
- contraste y alternativas al color;
- tecnologías de asistencia.

### Seguridad

- protección del área administrativa;
- validación de entradas;
- producto de base relacional, credenciales, aislamiento de red y despliegue;
- registro de acciones administrativas.

### Confiabilidad e integridad

- recuperación ante fallos;
- copias de seguridad;
- consistencia de mapas guardados ante cambios de catálogo;
- migraciones y compatibilidad de versiones.

### Mantenibilidad

- arquitectura y tecnologías;
- estrategia de pruebas;
- estándares de código;
- observabilidad y diagnóstico.

### Privacidad

La primera versión no tiene cuentas. Está pendiente confirmar si se recopilará cualquier dato personal, telemetría o analítica.

Ningún punto de esta lista constituye todavía un requisito aprobado.
